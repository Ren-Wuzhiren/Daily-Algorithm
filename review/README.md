# Review 复习档案

每次「无提示重写」的当次手写版本，独立归档于此，方便回看每轮书写痕迹与进步曲线。

- **命名**：`Review_<题号>_<题名>.java`（如 `Review_1_TwoSum.java`）
- **流程**：说「开始复习 <题号>」→ Codex 在本目录生成空方法体文件（零提示）→ 你写 → 验收（并入 `Lc_` + 跑测试 + 登记）→ **本文件保留归档**
- **标注**：文件头注释记录日期 / 轮次 / 结果（✅ 独立 AC / 🟡 提示后 AC / 🔴 看答案后 AC）
- **注意**：本目录不进 Maven 构建，仅作档案；解法正文以 `src/main/java/LeetCode_*/Lc_*.java` 为准
