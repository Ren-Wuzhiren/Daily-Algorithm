# Java_Daily_Algorithm 每日算法题典

一个面向**大厂校招/实习面试**的 Java 算法刷题仓库，采用「套路 + 复习队列 + 数据驱动题单」的因材施教模式。

- 语言：Java（Maven + JUnit4）
- 目标：2027 年底（大三上结束）具备大厂算法面试能力
- 节奏：每天 30–45 分钟（忙时低保 15 分钟）
- 题源：主线=代码随想录 · 框架=labuladong · 参考/进阶=灵茶山艾府

## 每日流程（三明治）

1. **前 5 分钟**：复习队列 1–2 道旧题（3/7/14 天档）
2. **25–35 分钟**：1 道新题——先独立想；超时走[卡住兜底协议](#卡住兜底协议)
3. **后 5–10 分钟**：写复盘（见 [TEMPLATE.md](TEMPLATE.md)），AI 只做讲解/对比

> 断更 ≠ 失败：连续断 ≥7 天才触发「回血」——用 2–3 天只刷复习队列。

## 卡住兜底协议

- 时间盒：easy 20 分钟 / medium 30 分钟 / hard 默认学习型
- 超时按级泄题：L1 套路提示 → L2 思路骨架 → L3 完整题解（AI 禁止一步到位）
- 看完任何一级必须**合上答案独立重写到 AC**
- 完成等级 → 复习队列：独立 AC→7/14 天；L1/L2 后 AC→3/7 天；L3 后能默写→1/3 天；仍不懂→1 天 + 降级换同套路简单题

## 命名规范

- 题解类/文件：`Lc_<题号>_<题名>`，如 `Lc_206_ReverseLinkedList.java`；配套测试为 `Lc_<题号>_<题名>Test.java`
- 按套路分包：`LeetCode_<套路>`（沿用现有 `LeetCode_SlidingWindow` 等）
- 特殊题号（如 面试题 16.24）：用去点数字命名（`Lc_1624_…`）
- 每题必配 JUnit 测试（官方示例 + 易错/边界，见 TEMPLATE.md）；完成后在进度总表 + 打卡模板登记

## 周复盘（每周日，30 分钟）

1. 把本周题单完成情况回填进度总表
2. 按「独立 AC 率」调整套路配额：<60% 加练 1–2 题；≥80% 降权或升难度
3. 生成/更新下周题单（`problem-set/`）
