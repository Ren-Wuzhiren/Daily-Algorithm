# 2026-09-25 · Lc_21 合并两个有序链表（链表/合并 · easy）

## 速览（手机碎片时间 5 分钟）

- **套路**：链表/双指针合并（dummy + tail）
- **一句话思路**：两个指针分别扫描两条有序链表，每次把较小的当前节点接到合并结果末尾。
- **我的卡点**：曾把 `tail.next` 接成当前节点的后继，并让两个遍历指针交叉前进；理解 `dummy + tail` 后跑通。
- **新增词汇**：合并结果的末尾 → `tail`；接上被选中的当前节点 → `tail.next = list1`；接上剩余整段 → `tail.next = list1 != null ? list1 : list2`。
- **一句收获**：合并链表时，每轮只做两件事：接上“当前节点”，然后只移动“被选中的那条链表”。

### 题目契约

- 输入：两个按非递减顺序排列的单链表 `list1`、`list2`
- 输出：合并后的有序单链表，复用原节点
- 边界：任意一条链表可以为空

### 思路拆解

1. `dummy` 固定合并结果的占位头，`tail` 指向结果末尾
2. 当两个链表都非空时，比较当前节点并接上较小者
3. 只移动被选中的链表指针，再移动 `tail`
4. 一条链表走完后，把另一条链表的剩余整段接上
5. 返回 `dummy.next`

### 复杂度

时间 O(m + n) / 空间 O(1)
