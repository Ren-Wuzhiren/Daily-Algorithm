# 2026-09-03 · Lc_26 删除有序数组中的重复项（数组/双指针 · easy）

## 速览（手机碎片时间 5 分钟）

- **套路**：数组/同向双指针（快慢指针）
- **一句话思路**：快指针遍历，遇到「新元素」（`!=` 前一个）就原地覆盖到慢指针位并推进；首元素无条件保留。
- **我的卡点**：① slow 初值 0 → 首元素被覆盖丢失（[1,1,2] 返回 1）② `return nums[slow]` 误返回数组元素，无重复时会越界。
- **新增词汇**：慢指针 = 下一个可写位置 → `int slow = 1;`；判新元素 → `nums[fast] != nums[fast-1]`；返回长度 → `return slow;`。
- **一句收获**：数组首元素一定是新元素 → slow 从 1 起；返回的是「长度」不是元素。
- **明日复习项**：🟡 3/7 天档 → 9.6 无提示重写。

### 题目契约

- 输入：升序数组 `nums`
- 输出：去重后长度 `k`，并**原地**修改 `nums` 前 k 位
- 约束：O(1) 额外空间；`1 <= nums.length <= 3*10^4`

### 思路拆解

1. `slow = 1`：`nums[0]` 一定是新元素，直接保留
2. `fast` 从 1 遍历：`nums[fast] != nums[fast-1]` → 新元素 → `nums[slow++] = nums[fast]`
3. 返回 `slow`（已写入个数 = 去重后长度）

### 复杂度

时间 O(n) / 空间 O(1)
