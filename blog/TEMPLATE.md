# 每日算法 Blog 模板（分层版）

> 用途：每天 AC 后由 Codex 生成一页 Blog，**正文速览**供手机碎片时间 5 分钟扫读，**完整分析**折叠在 `<details>` 里按需深读。文件命名 `blog/YYYY-MM-DD-<题号>-<题名>.md`。

```markdown
# YYYY-MM-DD · Lc_<题号> <题名>（<套路> · <难度>）

## 速览（手机碎片时间 5 分钟）

- **套路**：<套路名>
- **一句话思路**：<一句话>
- **我的卡点**：<今天卡在哪>
- **新增词汇**：`<中文意图> → <Java 表达>`
- **一句收获**：<一句话>
- **明日复习项**：<档位> → 下次无提示重写日期

<details>
<summary>完整分析（可选深读）</summary>

### 题目契约

<输入 / 输出 / 约束 / 评测逻辑>

### 思路拆解

<分步骤说明>

### 复杂度

时间 O(?) / 空间 O(?)

### 变式自测

- [ ] <变式题 1>
- [ ] <变式题 2>
</details>
```

> 低保日（忙时 15 分钟）可只写速览 3 行：一句话思路 / 新增词汇 / 明日复习项。
