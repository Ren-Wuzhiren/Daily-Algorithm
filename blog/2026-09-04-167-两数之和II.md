# 2026-09-04 · Lc_167 两数之和 II（数组/双指针 · medium）

## 速览（手机碎片时间 5 分钟）

- **套路**：数组/相向双指针
- **一句话思路**：左右指针从数组两端相向移动；和太小左移，和太大右移，命中后返回 1-based 下标。
- **我的卡点**：前三轮曾分别遇到暴力超时、右指针方向笔误、for 循环步进导致死循环；本轮算法结构无提示写对，只漏了 `left++` 的分号。
- **新增词汇**：有序数组相向搜索 → `left = 0; right = numbers.length - 1;`；和太小 → `left++`；和太大 → `right--`；返回 1-based 下标 → `left + 1`、`right + 1`。
- **一句收获**：算法结构写对后，也要做一次编译检查；语法错误不等于算法思路失败。
- **明日复习项**：✅ 本轮无提示算法重写 AC；下次按 7/14 天复习队列安排。

### 题目契约

- 输入：升序整数数组 `numbers`，以及 `target`
- 输出：两个下标，题目要求从 1 开始
- 保证恰有一个解；额外空间 O(1)

### 思路拆解

1. `left` 指向最小值，`right` 指向最大值。
2. 若两数之和小于 `target`，左侧需要更大的数，因此 `left++`。
3. 若两数之和大于 `target`，右侧需要更小的数，因此 `right--`。
4. 相等时返回 `{left + 1, right + 1}`。

### 复杂度

时间 O(n) / 空间 O(1)
