## 速览（手机碎片时间 5 分钟）

- **套路**：链表/指针反转（三指针 prev / curr / next）
- **一句话思路**：从前往后走，一边走一边把当前节点的 `next` 指向前一个节点；改箭头前先把"后路"存进 `next` 变量。
- **我的卡点**：① 初始误想成"两两交换"甚至"排序"——方向错 ② curr 起点 / 翻转对象 / 前进 / 返回值四处写错 ③ 终于写对后，ListNode 定义在 Solution 内部，力扣报 `ListNode cannot be converted to Solution.ListNode`。
- **新增词汇**：三指针初始化 → `prev = null; curr = head;`；先存后路 → `ListNode next = curr.next;`；翻箭头 → `curr.next = prev;`；接力棒前进 → `prev = curr; curr = next;`；新头 → `return prev;`；ListNode/TreeNode 由力扣提供，本地版放提交区域外。
- **一句收获**：反转的难点不在"翻转"这个动作，而在于"改箭头会丢掉后路"——**先存后路，再翻箭头**，这是所有链表指针题的第一原则。

### 题目契约

- 输入：单链表头节点 `head`
- 输出：反转后的头节点；原地修改指针，不新建节点、不比较值
- 约束：节点数 0 ≤ n ≤ 5000

### 思路拆解

1. `prev = null`：第一个节点的"前一个"是空——反转后它成为尾节点
2. `curr = head`：从原头节点开始处理（从 `head.next` 起会漏掉节点 1）
3. 每轮四步：存后路 `next = curr.next` → 翻箭头 `curr.next = prev` → 接力 `prev = curr` → 前进 `curr = next`
4. 循环结束时 `curr == null`，`prev` 停在最后一个节点——它就是新头 → `return prev`

### 复杂度

时间 O(n) / 空间 O(1)
