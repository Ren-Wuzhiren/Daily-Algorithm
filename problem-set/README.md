# 题单定制方法（因材施教 · 数据驱动 · 滚动更新）

## 题源角色分工

| 来源 | 角色 | 用法 |
|---|---|---|
| 代码随想录 | 主线 | 面试全覆盖 + 推荐顺序 + 配套题解，题单主体 |
| labuladong | 框架 | 每套路先读 1 篇框架文章 + 做 1 道模板题建骨架 |
| 灵茶山艾府 | 参考/进阶 | 卡住查高质量题解、按难度分定位、进阶难题、周六模拟可选周赛题 |

## 合并规则

- 三源按**题号去重**：同一题只出现一次，标注来源
- 主线顺序 = 代码随想录：数组 → 链表 → 哈希表 → 字符串 → 双指针 → 栈队列 → 二叉树 → 回溯 → 贪心 → DP → 单调栈 → 图论

## 题单字段说明

| 字段 | 含义 |
|---|---|
| 题号/题名 | LeetCode 题目标识（按题号去重） |
| 套路 | 属于哪个套路（对应 `notes/`） |
| 难度 | easy / medium / hard |
| 角色 | 模板题 / 新课 / 复习 / 限时模拟 / 自测 |
| 复习时间点 | 3/7/14 天复习档位（周复盘时填） |
| 选题理由 | 为什么选这道题（模板/高频/补弱点/变式） |
| 来源 | 代码随想录 / labuladong / 灵茶山艾府 |

## 生成流程（每周日执行）

1. 更新「套路熟练度矩阵」（下方）
2. 学习顺序 = 面试频率 × 熟练度；生疏且高频先学
3. 配额：生疏 5-6 题 / 会但不熟 3-4 题 / 熟练 1-2 题（维持）
4. 大二上课程同步：每章课程插 2-3 道「课程题」
5. 动态调整：套路独立 AC < 60% 加练 1-2 题；≥ 80% 降权或升难度
6. 生成下周题单文件（`phase-N-xxx.md`）
