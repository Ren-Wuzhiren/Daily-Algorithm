# 03 哈希表 / 计数

状态：🟡 已学待精（219、1128、1679、2260、面试题16.24）

## 一句话

哈希表 = 用空间换时间，把「查找是否存在 / 计数」从 O(n) 降为 O(1)。

## 框架要点

- 两数之和：遍历时查 map 是否已有 target-x（先查后插）
- 计数：HashMap 统计频率；值域小时用 int[] 更快
- 去重 + 保序：LinkedHashMap / Set 判重

## 易错点

- 两数之和「先查后插」顺序不能反
- 用数组下标计数时注意值域与负数偏移
