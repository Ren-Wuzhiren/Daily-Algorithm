## 27. 移除元素（数组/双指针）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 慢指针 = 下一个可写的位置 | `int slow = 0;` |
| 把「不是 val 的值」依次往前放 | `if (nums[fast] != val) nums[slow++] = nums[fast];` |
| 返回新数组长度（前 k 位） | `return slow;` |

### n刷踩坑

- 一刷（8.22）：漏「原地修改数组」的评测契约 → 测试 RED

## 167. 两数之和 II - 输入有序数组（数组/双指针）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 两个数相加等于 target | `numbers[left] + numbers[right] == target` |
| 和太小 → 需要更大的数 → 左指针右移 | `left++;` |
| 和太大 → 需要更小的数 → 右指针左移 | `right--;` |
| 相向走到碰头为止 | `while (left < right)` |
| 返回下标从 1 开始 | `new int[] {left + 1, right + 1}` |

### n刷踩坑

- 一刷（8.23）：暴力 O(n²) 超时 → 需相向双指针
- 二刷（8.26）：右指针方向笔误（`right--` 写成 `right++`）
- 三刷（8.31）：把相向双指针写成 for 循环，for 的 `right++` 与 else 的 `right--` 互相抵消 → 死循环 TLE；教训：谁动谁不动由比较结果现场决定 → 用 `while`，且右指针从末尾起
- 四刷（9.4）：算法结构无提示写对，仅漏 `left++` 分号；编译检查发现并修正 → 结论：算法正确也要做编译检查。

## 3. 无重复字符的最长子串（滑动窗口）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 记录每个字符「上次出现的位置」 | `Map<Character, Integer> last = new HashMap<>();` |
| 「这个字符出现过」 | `last.containsKey(c)` |
| 左边界收缩到上次出现位置之后 | `left = last.get(c) + 1;` |
| 从下标 0..len-1 逐个取字符 | `for (int i = 0; i < s.length(); i++) { char c = s.charAt(i); }` |

### n刷踩坑

- 一刷（8.24 默写 4m49s）：漏 `last.get(c) >= left` 的窗口内判断、忘 put 键值对
- 二刷（8.25）：独立 AC——「存在」用 `containsKey` 表达

## 209. 长度最小的子数组（滑动窗口）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 右端扩展窗口 | `sum += nums[right];` |
| 满足条件时收缩并更新答案 | `while (sum >= target) { ans = Math.min(ans, right - left + 1); sum -= nums[left++]; }` |
| 找不到时返回 0 | `return ans == Integer.MAX_VALUE ? 0 : ans;` |

### n刷踩坑

- 一刷（8.25）：答案记录时机、`Integer.MAX_VALUE` 笔误
- 二刷（8.28）：target=15 用例打脸——收缩后仍可能更短，必须持续收缩

## 1. 两数之和（哈希表）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 「补数」 | `target - nums[i]` |
| 补数的下标 | `map.get(target - nums[i])` |
| 存下值和它的下标 | `map.put(nums[i], i);` |
| 保证有解，但代码要兜底 | `return new int[0];` |

### n刷踩坑

- 一刷（8.26）：被 167 带偏用双指针惯性、map 键值方向写反、if 未补全
- 三刷（9.2）：把「当前元素」写成 `map.get(i)`（map 键是数组值不是下标 i → NPE）；`if`/`return` 自修对，`put` 存值靠提示 → 结论：查补数用 `nums[i]`，存值也用 `nums[i]`，map 用来查历史、不用于取当前元素

## 242. 有效的字母异位词（哈希/计数）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 用计数数组当「种类+数量」的账本 | `int[] count = new int[26]; count[c - 'a']++;` |
| 第二个字符串来对账 | `count[c - 'a']--;` |
| 账本是否清零（全 0 判定） | `for (int n : count) if (n != 0) return false;` |

### n刷踩坑

- 一刷（8.28）：循环嵌套重复计数、count 声明位置、全 0 判定
- 二刷（9.4）：先写 `char[]`；把 t 的抵消循环嵌套进 s 的统计循环，并重复扣减外层字符；L2 后拆成两趟循环并使用 `t.charAt(j)` → 结论：计数用 `int[]`，s 加一/t 减一并列执行

## 20. 有效的括号（栈）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 压栈（放到栈顶） | `stack.push(e);` |
| 弹栈（取走并返回栈顶） | `stack.pop()` |
| 看栈顶（只看不取） | `stack.peek()` |
| 栈是否为空 | `stack.isEmpty()` |
| 左括号压入「对应的右括号」 | `stack.push(')');` → 匹配只需 `stack.pop() != c` |

### n刷踩坑

- 一刷（9.1）：① 开头判空放错位置 ② 左括号用 peek（该 push） ③ 重写把 `return stack.isEmpty()` 写成 `return true`，被 `"["` 用例抓住 → 结论：判空只有两个位置（右括号分支 + 循环结束）
- 二刷（9.2）：`return true` 误放 `for` 循环内 → 第一次迭代就提前宣布成功（`"("` 返回 true）；主体独立写对，删掉循环内 `return true` 后 AC → 结论："成功出口"只在循环结束后 `return stack.isEmpty()`

## 26. 删除有序数组中的重复项（数组/双指针）

### 词汇表

| 中文意图 | Java 表达 |
|---|---|
| 慢指针 = 下一个可写位置（首元素保留） | `int slow = 1;` |
| 判断是否「新元素」（有序数组重复必相邻） | `nums[fast] != nums[fast - 1]` |
| 原地覆盖 | `nums[slow] = nums[fast]; slow++;` |
| 返回去重后长度 | `return slow;` |

### n刷踩坑

- 一刷（9.3）：① `slow` 初值 0 → 首元素被覆盖丢失（`[1,1,2]` 返回 1）② `return nums[slow]` 误返回数组元素，无重复数组越界 → 结论：首元素必保留 → `slow` 从 1 起；返回「长度」= `slow`
