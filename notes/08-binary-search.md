# 08 二分查找

状态：🔴 待练习

## 一句话

二分 = 在**单调性**上做区间缩减；关键是「边界开闭」和「找左边界 / 右边界」两个变体。

## 框架要点

- 基础：while left <= right，mid = left + (right - left) / 2
- 左边界：nums[mid] >= target 时 right = mid - 1；右边界对称
- 二分答案：对答案二分（如 875 爱吃香蕉的珂珂）

## 易错点

- 死循环：left/right 的移动必须保证区间收缩
- 防溢出：用 left + (right - left) / 2
