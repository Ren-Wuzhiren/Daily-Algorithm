# 07 二叉树

状态：🔴 待练习（数据结构课学过理论，尚未刷题）

## 一句话

二叉树 = 递归的练习场：先想「每个节点要做什么」，再想「遍历顺序」。

## 框架要点

- 前 / 中 / 后序：递归模板（终止条件 → 递归左右）；迭代用栈
- 层序：BFS 队列，按层 size 循环
- 递归三要素：参数与返回值、终止条件、单层逻辑
- BST 性质：中序遍历递增 → 验证/搜索类题目的钥匙

## 易错点

- 递归忘写终止条件 → 栈溢出
- 先想清处理顺序（前/中/后序）再写单层逻辑
