# 09 回溯 / 递归

状态：🔴 待学习

## 一句话

回溯 = 递归 + 撤销选择，解决「组合 / 子集 / 排列 / 棋盘」类穷举问题，先画一棵递归树。

## 框架要点

```text
backtrack(路径, 选择列表):
    终止条件 -> 记录答案
    for 选择 in 选择列表:
        做选择
        backtrack(路径, 选择列表)
        撤销选择
```

- 组合 / 子集：start 控制不回头；排列：used[] 去重
- 去重先排序，再跳过「同一层重复」

## 易错点

- 撤销选择漏写 → 结果错乱
- 记录答案时拷贝路径（new 一份），别直接加引用
