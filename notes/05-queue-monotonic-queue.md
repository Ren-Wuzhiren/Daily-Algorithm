# 05 队列 / 单调队列

状态：🟡 已学待精（933、3829）

## 一句话

队列 = FIFO；单调队列 = 用双端队列维护窗口内最值，是「滑动窗口最大值」的标准解法。

## 框架要点

- 用栈实现队列 / 用队列实现栈：两个结构互相倒
- 单调队列（存下标）：入队时把队尾「小于新元素」的全弹出；过期元素从队头弹出
- 与 OS 联动：循环队列 ≈ 环形缓冲区；阻塞队列 ≈ 生产者-消费者

## 易错点

- 单调队列里存**下标**而不是值（便于判过期）
- 先清队尾再清队头，顺序别反
