# 02 滑动窗口

状态：🟢 最熟（8 题，多为定长滑窗）

## 一句话

滑动窗口三模式：**定长**（窗口长度固定）、**最小**（满足条件时收缩求最短）、**最大**（不满足条件时收缩求最长）。

## 框架要点

- 定长：先装够 k 个，再右进左出，维护窗口统计
- 最小 / 最大：右指针扩张 + 左指针收缩，用 while 维护「不变量」
  - 最小：while 满足条件 → 更新答案 → 收缩
  - 最大：while 不满足条件 → 收缩 → 更新答案
- 窗口统计常用：int[] cnt（字符） / HashMap + need/window 计数
