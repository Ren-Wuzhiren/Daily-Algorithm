# 04 栈 / 单调栈

状态：🟡 已学待精（1441、844）

## 一句话

栈 = 后进先出，处理「相邻配对 / 最近相关」；单调栈 = 找每个元素**左边/右边第一个更大/更小**，O(n)。

## 框架要点

- 括号匹配 / 退格：遇左入栈、遇右弹栈
- 单调栈模板（找右边第一个更大）：

```text
for i in 0..n-1:
    while 栈非空 && nums[栈顶] < nums[i]:
        弹出，其下一个更大元素 = nums[i]
    入栈 i
```

- 单调栈存**下标**，答案在弹出时计算
